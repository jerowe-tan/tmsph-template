# Toyota Type

Source: [Toyota Europe DX Playbook static assets](https://dx-playbook.toyota-europe.com/cds/get-started/setup/static/), downloaded 2026-09-10 from its linked `dxp-assets.zip`.

Bundled original WOFF2 files: Regular (400), Semibold (600), Bold (700). The official bundle does not include Book; Regular is the application's body-text choice, not a renamed Book font. Files load locally through Next.js; no font CDN request is needed.

[Toyota's typography guidance](https://brand.toyota.com/guidelines/visual/typography) permits Toyota Type for work on behalf of Toyota, including affiliates and global use. This is a Toyota-owned brand asset, not an open-source font for unrelated brands. Preserve these source and usage notes when copying assets.
